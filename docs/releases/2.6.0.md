# APD Project Management Dashboard 2.6.0

_Released 2026-11-25 (feature). Numbered 1.6 before the [renumbering](../renumbering.md) on 2026-11-25._

Faster pages and quicker everyday editing. No data is changed or deleted, and there are no database changes.

**Speed**
- Pages load with **one request** instead of dozens (a project page used to make about 38). This is the new `/api/batch` endpoint, which runs the same permission checks
- Going back to a page you've just visited shows it **instantly** from memory, then refreshes in the background
- Project sections, the PDF library and the photo map load only when needed, so the project page code is about 41 KB instead of 557 KB
- Grey **loading outlines** instead of "Loading…"

**Everyday use**
- **Change a project's status** straight from the dashboard table
- **+ New** in the top bar adds a task, action, risk, defect or site visit to any project, or a new project, from any page
- **Duplicate** on actions and risks. Actions' bulk bar can also **set a due date** or **reassign** the selected items
- **Today & Upcoming → Select…**: tick several items, then mark them complete or move their due date in one go
- **Ctrl+K** is now a command menu as well as search: jump to any page, add things, switch light/dark, or log out, using the arrow keys and Enter
- **My week** (G W): your overdue and this-week tasks and actions, permits and insurance expiring within 30 days, and payment claims awaiting certification, on the projects you manage
- **Hide empty sections** on a project (per project, in your browser; nothing is deleted)
- Formatted text boxes **autosave a draft** in your browser until you save, and offer to restore it if a form was closed. The browser also asks before leaving with unsaved text

**Look and feel**
- Dashboard table: the header row stays pinned while you scroll, a **Columns** menu shows or hides columns (remembered), and tasks show as a progress bar
- **Health trend**: dots for the last monthly reports' RAG, plus an arrow showing whether the project is improving, slipping or steady
- **Phones**: projects show as cards, and project pages have a bottom bar to add an action, defect or site visit, or go to photos
