# APD Project Management Dashboard 2.6.1

**Versions now work the same way as SirisOS.**

- Versions are **Section.Feature.Fix**: the last number for a fix or minor change, the middle for a new feature or bigger upgrade, and the first only for a significant new section. Each part counts on its own and never rolls over.
- The history was renumbered from 1.0.0. 1.3 (Monthly Reporting) became 2.0.0, the one new section so far, and 1.6 became 2.6.0. [`docs/renumbering.md`](../renumbering.md) lists every old number against its new one.
- `scripts/bump-version.sh fix|feature|section` updates `VERSION`, both `package.json` files and the README, and starts the release notes.
- Release notes live in `docs/releases/`, one file per version. `CHANGELOG.md` now points there.
- Merging a version change to main tags it `v<version>` and publishes a GitHub release from its notes.
- The left menu shows the full version (e.g. v2.6.1).
- A backend test checks that `VERSION`, both `package.json` files and the release notes all agree.

No app behaviour or data changes.

## Update

On the server: `git pull`, then `docker compose up -d --build`. The left menu should then show v2.6.1.
