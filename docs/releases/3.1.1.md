# APD Project Management Dashboard 3.1.1

**The "What's new" pop-up is now written for the people using the dashboard, with screenshots.**

## Changed
- **What's new** explains the latest features in plain words, with screenshots of Ideas & Notes, the monthly report import, the dashboard tiles and the renamed columns. Server and update steps stay in these release notes.
- The pop-up has its own notes, `frontend/src/whatsNew/whatsNew.md`, and pictures beside it. It shows once per version of those notes, so small fixes don't bring the same notes back.
- `scripts/sync-release-notes.sh` is gone. A test checks the pop-up's notes name a released version, that every picture exists, and that they leave out server steps.

## Update

On the server: `git pull`, then `docker compose up -d --build`. Nothing in the database changes. Everyone sees the new What's new once.
